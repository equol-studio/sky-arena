# ワリーナ ドラフト盤

サマナーズウォー ワールドアリーナ（RTA）の**ピック/BAN補助ツール**。単一HTMLで動作し、外部通信なし・オフライン可。

**公開URL**: https://equol-studio.github.io/sky-arena/

## できること

- **ドラフト盤**: 敵軍 / 自軍を並べ、BAN・採用・PICKを記録。各陣営のPICK枠（リーダー＋4）を可視化
- **BAN推奨**: 未BANの最脅威を、脅威度・実BAN率・スキルとともに提示
- **刺さりピック**: 自分の所有キャラの中から、相手の編成に噛み合う駒を理由付きで優先度順に提示
- **モンスター詳細**: どの駒でもタップすると、スキル（S1/S2/S3・全体判定・効果）と脅威タグ、刺さる対策軸を表示
- **所有キャラ登録**: 保有モンスターとルーン実数値（速度・クリ率・的中・抵抗など）を記録
- **データ引き継ぎ**: 登録内容をJSONで書き出し／取り込み（端末間の移行用）

## データについて

収録 **1,894体**（入手可能な覚醒済み＋未覚醒ベース）。

- モンスターの属性・スキルは [SWARFARM](https://swarfarm.com) の構造化データ（公式効果ID）から機械的に導出。発動確率（全体25%以上／単体30%以上）で足切りし、低確率procを「持ち」と誤表示しないようにしている
- 一部の主要メタは実BAN率（swarena の Guardian 帯統計）を反映
- 日本語名は既知のもの以外は変換によるもので、ゲーム内の公式表記と異なる場合がある

ピック判定は**キャラ相性（スキルの噛み合い＋属性相性）のみ**で行う。相手のルーンは知り得ないため、速度勝負や的中/抵抗の計算は意図的に行っていない。

## 使い方

ブラウザで開くだけ。スマホでは「ホーム画面に追加」でアプリのように使える。登録データは端末内（localStorage）に保存され、外部には送信されない。
